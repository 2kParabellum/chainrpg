# План: дружочки, подиумы способностей, цепочка-плётка

План для исполнителя. Прежде чем начать, прочитай `agent.md`, `architecture.md`, `game_design.md`, `characters.md` и `chambers.md`.
Правила из `agent.md` и `architecture.md` действуют в полную силу: шаблон файла, порядок `<script>`, слои,
«render не меняет состояние», «уровни — только данные», характеристики копируются в сущность.
После выполнения этот файл удалить (так было и с прошлым планом).

## Что хочет пользователь (итог обсуждения)

1. **Все союзники одинаковые.** Лучник, Медик, Воин, Факир удаляются. Вместо них — один тип союзника, **«Дружочек»**.
   В базовом виде он умеет только бить в ближнем бою.
2. **Подиумы** — новые объекты на карте: светящаяся клетка на полу. Когда звено цепочки проезжает по подиуму,
   оно получает способность подиума **вместо** текущей:
   - **подиум стрельбы** — звено стреляет (дальняя атака вместо ближней);
   - **подиум лечения** — звено становится медиком: лечит цепочку и не атакует.
   У звена одна способность за раз, новый подиум её заменяет.
3. **Способность живёт, пока звено в цепи.** Дружочек, покинувший цепочку любым способом (таран Бычка,
   гарпун Скорпиона, бросок клавишей X), снова становится обычным. Подобранный обратно — тоже обычный.
4. **Подиумы действуют и на Героя.** Герой из цепочки не выпадает никогда, поэтому свою способность не теряет
   (пока не проедет по другому подиуму).
5. **Герой всегда ведёт.** Смены ведущего больше нет (клавиши 2–9 удаляются). **Меню порядка (C) удаляется целиком** —
   переставлять дружочков между собой тоже нельзя. Клавиша X (бросить последнего) остаётся.
6. **Дружочков на картах много.** Предел цепочки (вместе с Героем): **5 на Learn the Ropes, 10 на Playground**.
   Дружочков на карте заметно больше, чем мест, — потерянного можно заменить.
7. **Цепочка движется как плётка**: у звеньев появляется инерция — на поворотах хвост заносит, при остановке
   звенья проскакивают и возвращаются.
8. **Старые механики персонажей удаляются полностью**: щиты и сапоги Воина, огонь, горшок и огненный конус Факира,
   регенерация и рассеивание облаков Медика, ножи, копьё, револьвер. Вместе с ними — всё, что держалось только на них.

## Этап 5. Цепочка-плётка (инерция звеньев)

Сейчас `followChain` двигает звено к его точке на следе почти жёстко (`max(followSpeed, d·catchUpGain)`).
Нужно: у каждого звена своя скорость, к точке следа его тянет **пружина с затуханием**. Тогда на поворотах звенья
по инерции выносит наружу, а при остановке ведущего они проскакивают вперёд и возвращаются — это и есть «плётка».
К хвосту пружина мягче, поэтому хвост мотает сильнее всего.

### 5.1. Параметры (`config/tuning.js`, в `CHAIN`)

```js
whip: {
  enabled: true,     // false — старое жёсткое следование (для сравнения при настройке)
  stiffness: 70,     // жёсткость пружины у первого звена за Героем (1/с²)
  tailSoftness: 0.6, // на сколько жёсткость падает к последнему звену (0 — везде одинаково)
  damping: 0.35,     // доля от критического затухания: меньше — сильнее раскачка
  maxSpeed: 420,     // предел скорости звена
  maxLag: 60,        // дальше этого от своей точки звено тянется по-старому, без инерции (страховка у стен)
},
```

### 5.2. Алгоритм (`game/chain.js`, `followChain(a, dt, i)`)

```
target  = trailPointAt(i * spacing)
tv      = (target - a.prevTarget) / dt       // скорость точки следа; при первом кадре — 0
a.prevTarget = target
t       = (i - 1) / max(1, maxParty() - 2)    // 0 у второго звена, 1 у последнего возможного
k       = stiffness * (1 - tailSoftness * t)
c       = 2 * damping * sqrt(k)
acc     = k * (target - pos) + c * (tv - v)   // пружина к точке + затухание относительно движения точки
v      += acc * dt;  |v| ≤ maxSpeed
normal  = moveAndCollide(a, v.x*dt, v.y*dt, world.moveBlockers)
если normal — убрать из v составляющую в стену (как `slideAlongWall` у ведущего)
если |target - pos| > maxLag — старое поведение: шаг к точке со скоростью max(followSpeed, d·catchUpGain), v *= 0.5
```

Затухание считается **относительно скорости точки следа** (`tv - v`), а не абсолютной скорости: так звено не отстаёт
на прямой, а раскачивается только когда ведущий поворачивает, разгоняется или тормозит.

Хранить `prevTarget` в юните; при вербовке/подборе (`tryRecruit`) сбрасывать `prevTarget = null`, `vx = vy = 0`.
`dt` бывает маленьким — при `dt <= 0` шаг пропускать. `tv` ограничить (например, `2 × maxSpeed`), чтобы скачок
следа (рестарт, первый кадр) не давал рывка.

### 5.3. Настройка на глаз

- Хорошо: при резком развороте хвост из 4–9 звеньев заметно заносит дугой наружу и он догоняет за ~0.5–1 с;
  при остановке звенья проезжают на 5–15 px и откатываются; на прямой цепочка ровная, дистанция ~36.
- Звенья налезают друг на друга при остановке → поднять `damping` или `stiffness`.
- Хвост застревает на колоннах в проходах → уменьшить `maxLag` или `tailSoftness`.
- Слишком «деревянно» → снизить `damping` до 0.25.

### 5.4. По желанию (если останется время и не усложнит код)

- Тонкая линия-«верёвка» между соседними звеньями, чтобы изгиб плётки был виден (рисуется в `renderer.js`).
- Таран Бычка по звену, которое **не** вылетело, добавляет ему толчок в скорость — цепочка видимо дёргается.

Проверка: 30 секунд езды восьмёрками и резких разворотов на Playground с 10 звеньями — цепочка не рвётся,
звенья не проходят сквозь стены, не улетают; проход между комнатами Learn the Ropes проходится без застревания хвоста.

## Как проверять

Автотестов нет. Запуск: `python -m http.server 8765` (см. `.claude/launch.json`), браузер — Chromium через Playwright
(`/opt/pw-browsers`, ничего не скачивать). Проверки — скриптами в консоли страницы через `window.Game`
(телепорт Героя: поставить `state.party[0].x/y` и `state.moveTarget`), плюс живой запуск:

- оба уровня из меню, рестарт, возврат в меню; консоль чистая;
- число дружочков на старте: Learn the Ropes — 9, Playground — 16; предел 5 и 10 (`ЦЕПОЧКА ПОЛНАЯ`);
- ни один нейтрал и ни один подиум не пересекаются с препятствиями (проверить скриптом по `world`);
- подиумы: выдача, замена, потеря при таране/гарпуне/X, Герой получает и не теряет;
- стрелок бьёт только освещённых, медик лечит и не бьёт, базовый дружочек бьёт кулаком;
- плётка — см. этап 5;
- поиск по коду: не осталось ссылок на удалённые типы, оружия, `state.menu`, `swap`, `fires`.

Коммитить по этапам, с понятными сообщениями на русском, как в истории репозитория.
