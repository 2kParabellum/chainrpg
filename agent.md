# Agent

Инструкция агенту, как работать с md-файлами этого проекта.

## Файлы

- 'architecture.md' - актуальная архитектура проекта и правила зависимостей между модулями.
- `game_design.md` — актуальная логика игры. Источник правды по механикам.
- `characters.md` — персонажи и их характеристики.
- `current_state.md` — краткое текущее состояние проекта.
- `agent.md` — эта инструкция.

## Правила

- Каждое значимое изменение механик игры отражай в `game_design.md`, так чтобы он оставался актуальным.
- После значимой задачи обновляй current_state.md: что сейчас реализовано, известные проблемы и ближайшие шаги. Старую информацию удаляй.
- `agent.md` трогать нельзя. Этот файл меняет только пользователь.
- Если меняются персонажи, роли или характеристики сущностей — обновляй `characters.md`.
- Не описывай в md-файлах реализацию (имена функций, структуру файлов кода), только игровой смысл.
- Перед правкой механик сначала сверяйся с текущими md-файлами, потом меняй код, потом синхронизируй документы.
- Прежде чем вносить изменения в игру сверяйся с architechture.md
- Если меняется архитектура или ответственность модулей — обновляй `architecture.md`.
